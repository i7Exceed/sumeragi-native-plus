Sumeragi Native+ · The Sumeragi experience, evolved. (Bahasa Indonesia)
========================================================================
Runtime port native Windows independen untuk Sengoku Basara 4 Sumeragi (PS4, CUSA01159).
Dikembangkan oleh i7Exceed. Berdasarkan Basara 4 Native PC karya Razz, SpartanPort, dan shadPS4.
Perangkat lunak bebas di bawah lisensi GNU GPL v2 atau lebih baru. Kredit: NOTICE.md.

Cara Menjalankan
  1. Letakkan dump game legal milik Anda (folder yang berisi eboot.bin) di folder "game\",
     atau klik tombol "Browse" di launcher untuk memilih lokasi folder lain di komputer.
     Opsional: Update terpisah dapat ditaruh di folder "update\", dan DLC di folder "dlc\".
  2. Buka "Sumeragi Native+.exe", lalu klik tombol PLAY.
     Peluncuran pertama akan menyiapkan game image dari eboot.bin (~1 menit).
     Proses ini otomatis diperbarui jika eboot.bin berubah.
  Shortcut "Play Sumeragi Native+.cmd" dapat dipakai untuk langsung menjalankan game.

Menu In-Game & Sistem Piala (Trophies)
  Tekan Insert pada keyboard, atau R3 + L2 (RS + LT) pada controller untuk menu pengaturan in-game.
  Tekan F8 pada keyboard, atau R3 + R2 (RS + RT) pada controller untuk melihat Daftar Piala in-game.
  Notifikasi piala terbuka (toast) muncul otomatis secara real-time saat piala tercapai.
  Tombol "🏆 Trophies" pada launcher untuk melihat progres 43 piala, filter, dan reset.
  Screenshot: F12. Navigasi tab: L1/R1 atau Q/E.
  Dokumentasi lengkap piala: docs/TROPHIES.md

Controller
  Stik XInput, DualShock 4, DualSense, serta yang didukung SDL berfungsi langsung.
  Stik lain: gunakan tombol "Map controller" di launcher.

Kendala & Laporan Masalah
  Sertakan file user\last_run.log (dan user\prepare.log jika persiapan game gagal).
